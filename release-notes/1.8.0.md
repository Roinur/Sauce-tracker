# Sauce Tracker 1.8

Sauce Tracker 1.8 is the discovery and performance release. It adds a private local Sauce Finder, makes Suggested Entries practical to revisit, expands Browser recommendations, and continues the internal cleanup needed to keep a large six-month-old codebase safe to change.

## Highlights

- Find the source of a shared or saved image against your own library with Sauce Finder.
- Build the image index incrementally with four bounded workers, pause it at any time, and resume without rebuilding completed hashes.
- Reopen Suggested Entries with cached results and thumbnails already present.
- Tap a dashboard recommendation and land on that exact row.
- See website-provided More like this recommendations directly in Browser details.
- Keep Browser comments, tag counts, incognito titles, local related-entry filters, and thumbnail previews consistent.
- Keep Today, Week, Month, Year, activity heatmaps, and reading-session days aligned with the phone's local timezone while timestamps remain UTC internally.
- Require the explicit Skip button to dismiss the Browser exit rating prompt without saving; back gestures and outside taps no longer close it.
- Use cleaner Tag and Entry Heatmap presentation without changing the underlying graph behavior.
- Keep imported galleries out of subscription updates while retaining them in full backup history.
- Benefit from a second architecture pass that splits Dashboard and Browser responsibilities into smaller, focused components.

## Sauce Finder storage

The index stores five 64-bit perceptual hashes plus entry/page metadata for each indexed image. It does not duplicate the source images. Actual database size is displayed in the Sauce Finder UI; typical storage is roughly 1 to 2 MB per 10,000 indexed images, depending on SQLite overhead.

## Install

1. Back up important Sauce Tracker data.
2. Download `Sauce-Tracker-1.8-release.apk` and `Sauce-Tracker-1.8-release.apk.sha256`.
3. Verify the checksum if the APK was obtained through a third party.
4. Install over a compatible existing Sauce Tracker installation or perform a fresh install on Android 8.0 or newer.

ADB update:

```powershell
adb install -r Sauce-Tracker-1.8-release.apk
```
