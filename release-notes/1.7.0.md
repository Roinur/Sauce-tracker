# Sauce Tracker 1.7

Sauce Tracker 1.7 completes the internal architecture rewrite while keeping the existing app and visual language intact. This release focuses on reliability with large libraries, safer background behavior, clearer errors, and a more useful Selected Entry view.

Highlights:

- Selected Entry now includes Parts, More like this, and Same artist.
- Previous/next Parts navigation works even when the destination is hidden by the active Library filters.
- Entry Heatmap keeps all entries as points and loads thumbnails only inside selectable 10%, 25%, 50%, or 100% viewport zones.
- Library content survives the Browser/app-switch return flow.
- Website and network failures now produce clearer messages and safer retry behavior.
- Procedural backups keep two recoverable previous versions.
- Subscription notifications open the relevant Subscriptions screen.
- Release signing credentials are no longer stored in tracked project settings.

Install:

1. Back up important Sauce Tracker data.
2. Download `Sauce-Tracker-1.7-release.apk` and its `.sha256` file.
3. Verify the checksum.
4. Install the APK over a compatible existing installation or as a fresh install.
